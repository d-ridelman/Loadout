## Microsoft Visual C++ runtime

`vcruntime140.dll`, `vcruntime140_1.dll`, `msvcp140.dll` and `msvcp140_1.dll` next to the programs are the redistributable
files of the Visual C++ runtime (Visual Studio `VC\Redist`), shipped app-locally so the programs start without the
Redistributable installed; they are covered by the Visual Studio license terms for distributable code.
